# Gemini Clone (HTML/CSS/JS)

This project aims to replicate the basic look and feel of Gemini's chat interface for educational and demonstration purposes.

## Features

*   Basic chat interface layout
*   User input area
*   Simulated bot responses
*   Responsive design (basic)

## Technologies Used

*   HTML5: Structure and content of the web page.
*   CSS3: Styling and presentation of the interface.
*   JavaScript: Handling user interactions and dynamic content updates.
